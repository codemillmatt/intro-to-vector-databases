🎯 Recall vs Latency

Understanding the fundamental tradeoff in vector search

💡 The Core Concept

Vector databases use approximate algorithms (like HNSW) to search billions of vectors quickly. The ef (exploration factor) parameter controls how thorough the search is:

• Low ef → Explores fewer nodes → Faster, but may miss relevant results
• High ef → Explores more nodes → Slower, but finds more relevant results
