🎯 Recall vs Latency

The fundamental tradeoff in vector search

💡 What You're Seeing

This demo uses 100,000 random vectors to show how approximate nearest neighbor (ANN) search works.

The ef parameter controls how thoroughly the HNSW algorithm searches:
• Low ef (1-8) → Quick but may miss the best matches
• High ef (128+) → Thorough but takes longer
